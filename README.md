# ClioScope – Atualizações

Repositório público dedicado à distribuição dos **APKs assinados** do ClioScope.

O código-fonte e a chave privada de assinatura permanecem no repositório privado.

## Como funciona

O aplicativo consulta `latest.json` para conhecer a versão mais recente, baixar o APK por HTTPS e verificar seu SHA-256 antes de solicitar a instalação ao Android.

Não coloque chaves `.jks`, senhas, tokens ou código-fonte privado neste repositório.

A publicação inicial ainda **não** foi executada.
